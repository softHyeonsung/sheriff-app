# 보안관 — 핵심 기능 5개 흐름 정리

흐름도 작성용 정리 문서. 각 기능은 실제 구현 코드 기준으로 작성함.

---

## 1. 게시물 (SNS 피드)

**기능 설명**
사진과 텍스트로 게시물을 작성하고 장소를 태그할 수 있다. 피드에서 좋아요·댓글·공유가 가능하며, 부적절한 게시물은 신고할 수 있다.

**흐름 순서**
```
피드 탭 진입
  → [+ 작성] 버튼
  → 사진 선택 + 텍스트 입력 + 장소 태그(카카오 장소검색)
  → 게시하기
  → Storage에 이미지 업로드 + Firestore posts 문서 생성
  → 피드에 실시간 반영 (onSnapshot)
  → 다른 유저: 좋아요 / 댓글 / 공유 / 신고
```

## 2. 장소 저장 (지도 핀)

**기능 설명**
지도에서 마음에 드는 장소를 1탭으로 저장해 "나만의 지도"를 만든다. 저장 수가 일정 기준을 넘으면 지도에 노출 우선순위가 올라간다.

**흐름 순서**
```
지도(Basic/My Own) 탭 → 장소 핀 탭
  → 바텀시트에서 [저장] 버튼
  → users/{uid}/savedPins 서브컬렉션에 저장 (1탭, 별도 확인창 없음)
  → 활동 점수 반영 (+5, 최초 저장 시 +15 보너스)
  → 5곳 저장 시 "동네 탐험가" 뱃지 자동 부여
  → My Own 탭에서 내가 저장한 핀만 모아보기
```

## 3. 관광지 추천

**기능 설명**
현재 위치 주변의 공식 관광지를 한국관광공사 TourAPI로 조회해 파란 핀으로 표시한다. 지도 모임 모드에서는 내가 방문(게시물 작성)한 장소가 랜드마크로 등급업하며, 아직 안 가본 주변 후보지를 우선 편입해 여행 코스를 자동 추천한다("빈칸 채우기" 방식).

**흐름 순서**
```
지도 탭 → 현재 위치 기준 반경 내 TourAPI 조회
  → 관광지 파란 핀으로 지도에 표시
  → (모임 모드) 내 게시물 기반 랜드마크 핀 집계 · 등급 표시
  → [코스 추천] 버튼
  → 주변 TourAPI 후보 중 미방문 랜드마크 우선 선별 ("빈칸 채우기")
  → 후보 없으면 "추천 코스 없음" 안내
  → 후보 있으면 Kakao/ODsay 경로 API로 순차 경로 계산
  → 지도에 코스 경로 시각화
```

## 4. 커뮤니티 기능 (동네 모임)

**기능 설명**
카테고리별 소모임을 만들고 참여 신청을 받는다. 모임장이 신청을 승인하면 참여자 간 채팅방이 자동 생성된다.

**흐름 순서**
```
커뮤니티 탭 진입
  → [모임 만들기]
  → 제목·카테고리·장소·인원·시간 입력
  → 모임 등록 (status: recruiting)
  → 다른 유저가 모임 목록/상세에서 확인 → [참여 신청]
  → 모임장이 신청 목록에서 승인 / 거절
  → 승인 시 채팅방 자동 생성 (chats 컬렉션)
  → 참여자끼리 채팅으로 소통
  → 정원 도달 시 status: full 자동 전환
```

## 5. 보안관 시스템

**기능 설명**
게시물 작성·좋아요 받기·장소 저장·모임 참여 등 활동에 따라 점수가 누적되고, 매월 1일 지역별 상위 10명에게 보안관 뱃지가 자동 부여된다. 보안관 배지 보유자의 게시물·저장 장소는 지도·피드에서 금색으로 강조되어 신뢰도를 나타내며, 부적절한 콘텐츠·사용자는 신고·차단으로 대응한다.

**흐름 순서**
```
유저 활동 발생 (게시물 작성 +10 / 좋아요 받기 +2 / 장소 저장 +5 / 모임 참여 +15 / 퀘스트 완료 +30)
  → Cloud Functions에서 sheriff_score 누적
  → 매월 1일 00:00 KST — 지역별 상위 10명 자동 집계 (scheduled function)
  → 보안관 뱃지 부여 (badge_list 갱신)
  → 보안관 배지 보유자의 게시물·저장 장소는 지도·피드에서 금색 테두리로 강조

(안전장치 — 신고/차단)
부적절한 게시물/사용자 발견
  → [신고하기] → 사유 선택 → reports 컬렉션 기록 → 운영자 검토
  → (필요 시) [차단하기] → blocked_users 반영 → 해당 유저 콘텐츠 전체 화면에서 자동 숨김
```
