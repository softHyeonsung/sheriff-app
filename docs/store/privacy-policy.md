# 보안관 개인정보처리방침

시행일: 2026-08-27

'보안관'(이하 '서비스')을 운영하는 개발자(이하 '운영자')는 이용자의 개인정보를 중요시하며,
「개인정보 보호법」을 준수합니다.

## 1. 수집하는 개인정보 항목

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 회원가입(소셜 로그인) | 이메일, 닉네임, 프로필 이미지, 로그인 제공자(카카오/애플/구글) | 카카오/애플/구글 로그인 연동 |
| 위치정보 | GPS 좌표(현재 위치), 주거지 인증 좌표 | expo-location (이용자 동의 시) |
| 콘텐츠 | 게시물 텍스트, 사진/미디어, 댓글, 채팅 메시지 | 이용자 직접 입력/업로드 |
| 서비스 이용 기록 | 저장한 장소, 팔로우 관계, 활동 점수(sheriff_score), 포인트 | 서비스 이용 과정에서 자동 생성 |
| 기기정보 | 푸시 토큰(FCM) | 알림 기능 이용 시 |

## 2. 개인정보 수집 및 이용 목적

- 회원 식별 및 로그인 유지
- 지도 기반 동네 콘텐츠(피드, 모임, 퀘스트) 제공
- 주거지 인증을 통한 하이퍼로컬 서비스 제공
- 보안관 점수·뱃지 산정 등 커뮤니티 신뢰도 시스템 운영
- 모임/퀘스트 매칭 및 채팅 기능 제공
- 알림(FCM) 발송

## 3. 개인정보의 보유 및 이용 기간

회원 탈퇴 시까지 보유하며, 탈퇴 즉시 파기합니다. 단, 관계 법령에 따라 보존이 필요한 경우
해당 법령이 정한 기간 동안 보관합니다.

## 4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만 서비스 제공을 위해
아래와 같이 처리를 위탁합니다.

| 수탁업체 | 위탁 업무 |
|---|---|
| Google Firebase (Authentication, Firestore, Realtime Database, Storage, Cloud Functions, FCM) | 인증, 데이터 저장, 실시간 채팅, 파일 저장, 알림 발송 |
| 카카오 (Kakao Login / Kakao Map) | 소셜 로그인, 지도·장소 검색 |
| 한국관광공사 (TourAPI) | 주변 관광정보 조회(위치 기반, 개인 식별 정보 미포함) |

## 5. 이용자의 권리

이용자는 언제든지 앱 내 프로필 설정에서 본인의 개인정보를 조회·수정할 수 있으며, 회원 탈퇴를
통해 개인정보 삭제를 요청할 수 있습니다.
