# 원스토어 앱 등록정보 초안 — 보안관

## 앱 이름
보안관

## 짧은 설명 (한 줄, 30자 내외)
지도로 만나는 우리 동네 이웃과 로컬 여행

## 상세 설명

우리 동네에서 무슨 일이 일어나고 있는지 지도로 한눈에 확인하세요.

**보안관**은 실시간 지도와 신뢰 기반 지역 활동 데이터를 결합한 하이퍼로컬 커뮤니티
앱입니다.

- 🗺️ **지도 중심 피드** — 앱을 열면 바로 우리 동네 지도가 보입니다. 동네 맛집, 명소,
  이웃들이 저장한 장소를 핀으로 확인하세요.
- 📍 **1탭 핀 저장** — 마음에 드는 장소를 지도에 바로 저장하고, 나만의 지도를 만들어보세요.
- 👥 **동네 모임** — 취미, 운동, 맛집 탐방 등 카테고리별 소모임을 만들고 참여하세요.
- 🎖️ **보안관 시스템** — 활동 점수가 쌓이면 보안관 뱃지를 획득합니다. 보안관이 저장한
  장소는 지도에서 금색으로 표시되어 신뢰도를 나타냅니다.
- 🧭 **로컬 여행 코스** — 주민들이 실제로 다녀간 장소 데이터를 기반으로 여행 코스를
  추천받으세요.

동네 주민이든 여행객이든, 보안관과 함께 진짜 동네를 경험해보세요.

## 카테고리
소셜/커뮤니케이션 (또는 라이프스타일)

## 키워드
동네, 커뮤니티, 지도, 모임, 로컬, 여행, SNS, 이웃

## 필요 권한 고지 (등록 시 사유 기재용)
- 위치정보: 현재 위치 기반 지도 표시, 주거지 인증, 주변 모임/퀘스트 검색
- 카메라/사진: 게시물·프로필 이미지 업로드
- 알림: 모임 승인, 댓글, 채팅 알림 (2차 MVP 이후)

## 스크린샷 (준비 필요)
원스토어는 세로 스크린샷 최소 2장(권장 4~8장) 필요. 아래 화면 위주로 촬영 권장:
1. 지도 메인 (Basic 탭)
2. 게시물 피드 / 바텀시트
3. 모임 생성·목록
4. 프로필 (보안관 뱃지)
